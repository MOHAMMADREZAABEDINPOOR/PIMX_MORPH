## ⚡ Project Overview

Engineers constantly waste time navigating sketchy online converter websites full of advertisements to encode Base64 strings or format JSON payloads, risking credential leaks.

**PIMX_MORPH** provides a clean, private alternative:
- 🔒 **100% Client-Side RAM Processing**: Data never leaves your machine.
- 🔄 **Bidirectional Encoders**: Base64, Hex, Binary, ASCII, URL-encode, HTML Entities, Morse code.
- ⚙️ **Cryptographic Hashes**: SHA-1, SHA-256, SHA-512, MD5, and HMAC signatures.
